# Aman Yadav - Portfolio

Personal developer portfolio built with React 19, TypeScript, and Vite featuring distributed systems, backend engineering, and applied machine learning projects.

🔗 **Live Portfolio:** [actas-aa.vercel.app](https://actas-aa.vercel.app/)

## 🚀 Featured Projects
- **PingGuard**: Distributed HTTP Uptime Monitoring Engine (FastAPI, Redis, Celery, PostgreSQL, Docker)
- **GateForge**: High-Throughput API Gateway & Distributed Rate Limiter (FastAPI, Redis, Lua, PostgreSQL, Docker, Prometheus)
- **EduPulse**: Academic Early-Warning & Student Forecasting Platform (FastAPI, PostgreSQL, Scikit-Learn, Docker)
- **EV Life**: Lithium-Ion EV Battery Remaining Useful Life (RUL) Prognostics Platform (PyTorch, 1D-CNN + LSTM, FastAPI, React)

## 🛠️ Tech Stack
- **Frontend:** React 19, TypeScript, Vite, Modern CSS Architecture
- **Backend & Distributed Systems:** Python, FastAPI, Django, Celery, Redis, PostgreSQL, Lua, Docker, Prometheus
